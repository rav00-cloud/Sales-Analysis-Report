# Sales Analysis Dashboard

## Overview
This project involves a dynamic Power BI dashboard to analyze sales data, offering insights into trends, customer behavior, and profitability.

## Objectives
1. Identify sales trends across regions and time.
2. Evaluate product performance and profit margins.
3. Enhance decision-making for inventory and marketing.

## Key Features
- **KPIs:** Total Sales, Profit, Average Order Value.
- **Visuals:** Line charts, bar charts, maps, and interactive filters.
- **Insights:** Region-wise performance, customer behavior, and product trends.

## Files
- `Sales Analysis report.pbix`: Power BI file.
- `Sales Report.xlsx`: Dataset used for the dashboard.
- `README.md`: Project documentation.

## How to Use
1. Download the `Sales Analysis report.pbix` file.
2. Open it in Power BI Desktop.
3. Interact with the dashboard to explore insights.
